#  ClimateTech × GIS

İklim değişikliği, mekânsal veri ve teknoloji kesişiminde yenilikçi bir dijital çözüm geliştiriyoruz.

Projemizin araştırma ve konsept geliştirme süreci devam ediyor. Şu anda fikrimizi **çalışan, ölçeklenebilir ve gerçek dünyada kullanılabilir bir teknolojiye dönüştürmek** için teknik ekibimizi oluşturuyoruz.

##  Ekibimize Katılın

Yazılım geliştirme sürecinde bizimle birlikte çalışmak isteyen geliştiriciler ve teknik ekiplerle iş birliği yapmak istiyoruz.

Özellikle;

* Frontend / Web Development
* Backend Development
* GIS / WebGIS
* Python
* JavaScript / TypeScript
* Veri görselleştirme
* Veritabanı ve API
* Yapay zekâ / veri analitiği
* Harita ve mekânsal veri teknolojileri

alanlarında katkı sağlayabilecek ekip arkadaşları arıyoruz.

Bireysel geliştiricilerin yanı sıra küçük yazılım ekipleriyle de iş birliğine açığız.

##  Proje Hakkında

Projemiz **iklim + GIS + veri + teknoloji + karar destek** kesişiminde geliştirilmektedir.

Özgün metodoloji ve teknik mimari, projenin mevcut geliştirme aşaması nedeniyle henüz kamuya açık olarak paylaşılmamaktadır.

Daha fazla bilgi için bizimle iletişime geçebilirsiniz.
